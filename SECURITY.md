# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
through GitHub: **Security → Report a vulnerability** on
[ECecillo/lib.go.sound](https://github.com/ECecillo/lib.go.sound/security/advisories/new).

Include what you found, how to reproduce it, and the impact you expect. The
project has a single maintainer, so reports are handled on a best-effort basis;
you will get an answer in the advisory thread, and a fix is published with a
GitHub security advisory once it is released.

## Supported versions

Security fixes go into the latest release (currently `v1.1.x`) and `main`.
